# Pendaftaran Event Kampus

Website ini dibuat untuk memudahkan pendaftaran peserta seminar *"Personal Branding di Era Digital"* secara online. Peserta dapat mendaftar, memilih kategori, dan melihat daftar peserta yang sudah terdaftar.


## Fitur

- Form pendaftaran dengan input:
  - Nama Lengkap
  - Email
  - Nomor HP
  - Kategori Peserta (Mahasiswa / Umum)
- Validasi input:
  - Semua input wajib diisi
  - Email harus mengandung karakter `@`
  - Nomor HP hanya boleh angka
- Batas kuota peserta: 50 orang
- Menampilkan daftar peserta yang sudah mendaftar
- Notifikasi berhasil atau error saat pendaftaran


## Teknologi yang Digunakan

- **HTML**: Struktur halaman
- **CSS**: Styling dan layout (flexbox / grid)
- **JavaScript**: Validasi form, penambahan peserta, penghitungan jumlah peserta


## Cara Menjalankan 💻

1. Clone atau download project ini.
2. Pastikan file `index.html`, `style.css`, dan `script.js` berada di folder yang sama.
3. Buka file `index.html` di browser (Google Chrome, Firefox, dll).
